# SQL 50 - LeetCode Solutions

This repository contains my solutions to the **LeetCode SQL 50 Study Plan**, a curated collection of SQL problems covering fundamental to intermediate SQL concepts including:

* SELECT statements
* Joins
* Aggregate Functions
* Sorting & Grouping
* Subqueries
* Advanced Joins
* String Functions

The SQL 50 study plan is designed to strengthen SQL skills commonly tested in technical interviews and real-world database work.
